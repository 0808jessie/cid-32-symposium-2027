# 2027 CID 第 32 屆國際設計學術研討會網站原型

此為多頁響應式 HTML/CSS 原型。可直接開啟 `index.html`，或在此資料夾執行 `python3 -m http.server 4173` 後瀏覽首頁。

## 頁面

- `index.html`：首頁、近期重要日期與主要入口
- `about.html`：大會主題與籌備委員資訊
- `call-for-papers.html`：六大徵稿子題、投稿日期與下載入口
- `speakers.html`：講者與工作坊
- `program.html`：5 月 21 日工作坊及 5 月 22 日研討會議程
- `venue.html`：場地、交通與無障礙資訊
- `registration.html`：報名時程、費率區塊與聯絡資訊

## 尚待確認

Logo、主視覺與其他照片均以佔位呈現；投稿及註冊網址、Word／LaTeX 範本、註冊費率、秘書處聯絡資訊、完整委員名單，以及論文發表場次表尚待提供或確認。英文切換目前為導覽預覽，英文全文未加入。

此原型依計畫書內容整理。活動日期以 2027 年 5 月 21 日（五）及 5 月 22 日（六）標示。
